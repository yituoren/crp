# 幕后操作手册

网址：`http://服务器IP`（主办赛前在群里发）。建议用手机浏览器打开后「添加到主屏幕」，方便比赛当天快速进入。

## 所有幕后

1. **注册**：主办把你的 ID 加入准入名单后，打开网址 → 「立即注册」→ 输入主办给你的 ID 和自己设的密码。密码不要用你常用的重要密码。
2. **登录后看「我的今日」**：顶部先选对赛段（EP1、EP2…），页面会显示你在这个赛段是跟队、站点还是机动。排班有变化会自动刷新。
3. **右上角绿点「实时同步中」** 表示在线。变红说明网络断了：页面仍能看，但记录操作会失败，恢复后重新点一次即可，不会重复记录。
4. 「赛段信息」可以看每个环节的说明、地址、线索图片和判定标准。

## 跟队

- 「我的今日」会列出你所跟队伍在本赛段的所有环节。队伍到达一个环节点「记录到达」，完成后点「记录完成」。每次会弹出一个时间表单，默认填的是服务器当前时间，一般直接点「确认记录」即可；如果是事后补记，把时间改成实际时间再确认。不能填未来的时间。
- 必须按环节顺序记录：前一个环节没记完成，下一个环节的按钮是灰的。点错了不要自己想办法改，联系主办撤销或修正。
- 只有主办点了「开始赛段」之后才能记录，赛段结束后也不能再记。
- 「货币与罚时」页面可以给所跟队伍加减货币（比如路上买线索、任务奖励），一定要填原因；其他队伍的货币和罚时由站点或主办操作。

## 站点

- 「我的今日」显示你驻守的环节、地址、开放时间、判定标准，以及所有队伍在该环节的到达/完成情况。队伍到站点「记录到达」，任务判定通过后「记录完成」。
- 绕道环节要选队伍选了哪一边；路障环节填完成人；快进环节记录成功/失败。
- 需要奖励或扣除货币、或给队伍补罚时，在「货币与罚时」页面操作，一定要填原因。罚时用「增加罚时」按钮；因主办或站点失误耽误了队伍时间，用「补充时间」按钮把时间补回去，结算时从最终用时里扣除。分钟数都填正数。
- 站点可以上传本环节的现场照片或线索图片（环节详情页底部）。

## 主办

**赛前**
- 「主办后台 → 准入名单」加入所有幕后 ID；「赛事设置」确认赛事名、初始货币、主办名单。
- 「赛段信息」编辑每个赛段的经费、环节（类型、说明、地址、线索原文、判定标准、附件）。每个赛段保留一个「PS 中继站」环节，结算时自动取它的签到时间。
- 环节类型决定默认行为，主办可逐个改：

| 类型 | 默认站点 | 默认记录 |
|---|---|---|
| SL 起跑线 | 需要 | 只记出发 |
| RI 路线信息 | 不需要 | 不记录 |
| TI 任务点 / DT 绕道 / RB 路障 / FO 快进 / Union 联合 / SB 减速带 / PK 对抗 / Trap | 需要 | 到达 + 完成 |
| UT 回转点 / YD 让路点 | 需要 | 打卡 + 施加对象 |
| PS 中继站 | 需要 | 只记签到 |

  路线信息如果带任务（例如“路线任务：记忆碑文”），把记录方式改成“到达与完成”即可。
- 「排班」为每个赛段指定跟队（对应队伍）和站点（对应环节）。同一队伍分了两个跟队或存活队伍没有跟队时页面会提示。

**赛中**
- 每个赛段出发前在「赛段信息」点「开始赛段」：状态变为进行中，本赛段经费自动发给所有存活队伍。赛段结束点「结束赛段」。
- 「实时大屏」看所有队伍位置、进度矩阵。
- 任何记录都可以在环节详情页「修改」；「终点结算」加罚时。
- 需要时在「我的今日」发公告，所有幕后立即看到。

**赛段结束**
- 「终点结算」点「按时间自动排名」，检查名次，把末位队伍勾选「本赛段淘汰」。
- 「主办后台 → 备份与重置」导出一次备份。

**忘记密码**：主办在「账号管理」里重置。所有修改都在「操作日志」里可查，操作日志和备份/重置只有管理员账号能进。
