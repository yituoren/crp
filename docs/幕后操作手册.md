# 幕后操作手册

网址：`http://服务器IP`（主办赛前在群里发）。建议用手机浏览器打开后「添加到主屏幕」，方便比赛当天快速进入。

## 所有幕后

1. **注册**：主办把你的 ID 加入准入名单后，打开网址 → 「立即注册」→ 输入主办给你的 ID 和自己设的密码。密码不要用你常用的重要密码。
2. **登录后看「我的」**：顶部先选对赛段（EP1、EP2…），页面会显示你在这个赛段是跟队、站点还是机动。排班有变化会自动刷新。
3. **右上角绿点「实时同步中」** 表示在线。变红说明网络断了：页面仍能看，但记录操作会失败，恢复后重新点一次即可，不会重复记录。
4. 「赛段」可以看每个环节的说明、地址、线索图片和判定标准；「进度」可以看所有队伍每个环节的开始、结束和用时。
5. **实时大屏**：电脑上固定在页面左侧；手机上向右滑一整屏就是「队伍当前位置」，再向左滑回到常规页面，底部两个小圆点表示当前在哪一屏。

## 跟队

- 「我的」会列出你所跟队伍在本赛段的所有环节。队伍开始一个环节点「记录开始」，完成后点「记录完成」。每次会弹出一个时间表单，默认填的是服务器当前时间，一般直接点「确认记录」即可；如果是事后补记，把时间改成实际时间再确认。不能填未来的时间。
- 必须按环节顺序记录：前一个环节没记完成，下一个环节的按钮是灰的。绕道要先选好哪一边、路障先填完成人、快进先填结果，才能点「记录完成」。记错了时间可以点「修改时间」改正，但不能把已记的时间清空，需要撤销请联系主办。
- 只有主办点了「开始赛段」之后才能记录，赛段结束后也不能再记。
- 「经费」页面可以给所跟队伍加减经费（比如路上买线索、任务奖励），一定要填原因；其他队伍的货币和罚时由站点或主办操作。

## 站点

- 「我的」显示你驻守的环节、地址、开放时间、判定标准，以及所有队伍在该环节的开始/完成情况。开始和完成时间由跟队记录，站点不用操作，只需判定任务并告知跟队。
- 本站点的罚时和补时直接在「我的」页面记录表下方操作，会标上所在环节；经费在「经费」页面操作。一定要填原因。罚时用「增加罚时」按钮；因主办或站点失误耽误了队伍时间，用「补充时间」按钮把时间补回去，结算时从最终用时里扣除。分钟数都填正数。
- 站点可以上传本环节的现场照片或线索图片（环节详情页底部）。
- 站在中继站的站点人员，本赛段可以在「进度」页最下方的排名结算里点「淘汰」标记末位队伍，也能取消。

## 直播员

- 排班为直播员后，本赛段所有数据（队伍位置、进度矩阵、经费、罚时、公告）都能看，但不能记录或修改；左侧大屏和「进度」页是主要工作界面。

## 主办

**赛前**
- 「后台 → 准入名单」加入所有幕后 ID；「赛事设置」确认赛事名、每队人数、主办名单。「队伍」页填好每队成员，之后各处按「编号 成员1&成员2」显示。
- 「赛段」编辑每个赛段的补充经费和环节顺序；点进某个环节，页面最上方就是编辑表单（类型、说明、地址、线索原文、判定标准），改完点「保存修改」，附件和队伍完成情况在同一页下方。每个赛段固定以中继站结尾，结算时自动取它的签到时间。
- 环节类型决定默认行为，主办可逐个改：

| 类型 | 默认站点 | 默认记录 |
|---|---|---|
| SL 起跑线 | 需要 | 只记出发 |
| RI 路线信息 | 不需要 | 不记录 |
| TI 任务点 / DT 绕道 / RB 路障 / FF 快进 / Union 联合 / SB 减速带 / FO 对抗 / Trap | 需要 | 开始 + 完成 |
| UT 回转点 / YD 让路点 | 需要 | 打卡 + 施加对象 |
| PS 中继站 | 需要 | 只记签到 |

  路线信息如果带任务（例如“路线任务：记忆碑文”），把记录方式改成“开始与完成”即可。
- 「排班」为每个赛段指定跟队（对应队伍）和站点（对应环节）。同一队伍分了两个跟队或存活队伍没有跟队时页面会提示。

**赛中**
- 每个赛段出发前在「赛段」点「开始赛段」：状态变为进行中，本赛段经费自动发给所有存活队伍。赛段结束点「结束赛段」。
- 左侧（手机上向右翻一屏）随时看队伍当前位置；「进度」页看每队每个环节的开始、结束、用时。
- 任何记录都可以在环节详情页「修改时间」；罚时在「进度」页中间；经费变动或罚时记错了，有权添加的人就能在对应列表里「撤销」，原记录划线保留，同时写一条反向记录，不会删除任何记录。
- 需要时在「公告」页发公告，重要的可以「置顶」；所有幕后的「公告」标签会出现红点，点开即消；已读状态记在账号上，换手机登录也不会重复提醒。

**赛段结束**
- 「进度」页最下方的排名结算会随签到和罚时自动更新名次，核对后把末位队伍点「淘汰」。
- 「后台 → 备份与重置」导出一次备份。

**忘记密码**：主办在「账号管理」里重置。所有修改都在「操作日志」里可查，操作日志和备份/重置只有管理员账号能进。
