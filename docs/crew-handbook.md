# 幕后操作手册

网址：`http://服务器IP`（主办赛前在群里发）。建议用手机浏览器打开后「添加到主屏幕」，方便比赛当天快速进入。

## 所有幕后

1. **注册并加入比赛**：打开网址 → 「立即注册」→ 起一个幕后 ID 和密码（不要用你常用的重要密码）。登录后进入个人主页，在「公共赛事」里找到本次比赛，输入主办给的邀请码点「加入」，之后它会出现在「我的比赛」里，点击进入。页面左上角的「返回」可以回到主页。
2. **登录后看「我的」**：顶部先选对赛段（EP1、EP2…），页面会显示你在这个赛段是跟队、站点还是机动。排班有变化会自动刷新。
3. **右上角绿点「实时同步中」** 表示在线。变红说明网络断了：页面仍能看，但记录操作会失败，恢复后重新点一次即可，不会重复记录。
4. 「赛段」可以看每个环节的说明、地址、线索图片和判定标准；「进度」可以看所有队伍每个环节的开始、结束和用时。
5. **实时大屏**：电脑上固定在页面左侧；手机上用底部的「大屏 / 页面」两个按钮切换，大屏就是「队伍当前位置」。

## 跟队

- 「我的」会列出你所跟队伍在本赛段的所有环节。每个环节只需要记一次：起跑线点「记录出发」，路线信息点「记录到达」，中继站点「记录签到」，其余环节点「记录完成」。环节的开始时间不用记，系统自动取上一个环节的结束时间（起跑线没有开始时间）。每次会弹出一个时间表单，默认填的是服务器当前时间，一般直接点「确认记录」即可；如果是事后补记，把时间改成实际时间再确认。不能填未来的时间。
- 路线信息（RI）和中继站（PS）的「名称」栏填的是目的地：RI 显示时自动带箭头，比如「→ 天安门」；PS 直接显示地名。
- 必须按环节顺序记录：前一个环节没记完成，下一个环节的按钮是灰的。绕道要先选好哪一边、路障先填完成人、快进先填结果，才能点「记录完成」。记错了时间可以点「修改记录」改正，但不能把已记的时间清空，需要撤销请联系主办。
- 只有主办点了「开始赛段」之后才能记录时间、操作经费和罚时（主办也一样）。
- 赛段结束后，或者队伍被淘汰、退赛之后，相关的时间、罚时、经费记录全部锁定，连主办也不能改，只有管理员可以。淘汰和退赛的队伍仍然留在列表里。
- 路障完成人从下拉里选本队成员；如果某人做路障的次数已经比队友多出设置的上限（默认 2），下拉里就不会出现他。
- 支线环节：主线进行中随时可以点「开始支线」，这时主线暂停计时、不能点完成；做完点「结束支线」，主线继续。支线不是必须做的，不进入就留空；主线完成之后支线就不能再改了。
- 联合环节：先在「合作队伍」里选好对方，对方也选了你们之后才能点「记录完成」；任意一方点了，两队同时记录完成。
- 绕道选择、路障完成人、快进结果等附加信息要等上一个环节记完（本环节自动进入进行中）才能填；记录完成后不能再原地改，需要点「修改记录」。
- 淘汰是自动的：主办在环节上设好「可淘汰」和「淘汰队数」（中继站固定可淘汰，默认 2 队），所有队伍到齐后，最后到的几队自动变成已淘汰，之后的环节不能再记录。记录改了会自动重算。
- 退赛由主办在「队伍」页操作：之前的记录保留，之后的环节留空。
- 「经费」页面可以给所跟队伍加减经费（比如路上买线索、任务奖励），一定要填原因；其他队伍的经费由主办操作。页面最上方的「背包」能看到各队余额，货币模式下还能看到各队买了什么。
- 货币模式的比赛有商店：类型选「商店购买」，选所在环节（只能是开放了商店的环节）和商品，金额自动按价格扣除。买错了在流水里「撤销」即可退货。
- 「我的」页面跟队表下方有「熔断」卡片：列出当前环节可用的熔断，倒计时结束按钮变为可点，点一下就用掉一次（货币比赛会显示并扣掉消耗），然后立刻开始下一次倒计时。
- 「我的」页面最下方可以给所跟队伍增加罚时或补充时间，必须选所在环节并填原因；其他队伍的罚时由站点或主办操作。

- 手机上如果页面像电脑版一样缩得很小，多半是浏览器开了「桌面版网站」（华为、小米等浏览器菜单里都有这个开关），关掉后刷新即可。

## 站点

- 「我的」按环节顺序显示你驻守的每个环节（可能不止一个）：地址、开放时间、判定标准，以及所有队伍在该环节的开始/完成情况。开始和完成时间由跟队记录，站点不用操作，只需判定任务并告知跟队。
- 站点也能给任何队伍加减经费，但只能记在自己驻守的环节上：在「我的」页每个环节下方的经费表单里操作。
- 本站点的罚时和补时直接在「我的」页面记录表下方操作，会标上所在环节，一定要填原因。经费由跟队和主办操作，站点不经手。罚时用「增加罚时」按钮；因主办或站点失误耽误了队伍时间，用「补充时间」按钮把时间补回去，结算时从最终用时里扣除。分钟数都填正数。
- 站点可以上传本环节的现场照片或线索图片（环节详情页底部）。
- 「进度」页的进度结算表按实时名次从上到下排列。中继站签到齐了之后，最后的几队会按环节设置自动淘汰，不需要手动操作。

## 直播员

- 排班为直播员后，本赛段所有数据（队伍位置、进度结算、经费、罚时、公告）都能看，但不能记录或修改；左侧大屏和「进度」页是主要工作界面。

## 主办

**赛前**
- 在进比赛之前的「账号管理」里可以停用账号、重置密码；比赛内「后台 → 赛事设置」确认赛事名、邀请码、每队人数；把邀请码发给所有人，凭邀请码进来的默认是幕后，在「后台 → 成员与主办」把其他主办设为主办。创建者固定为主办；管理员是全局角色，权限高于主办，不在这里设置。「队伍」页填好每队成员，之后各处按「编号 成员1&成员2」显示。
- 「赛段」编辑每个赛段的补充经费和环节顺序（电脑上直接拖动环节卡片换序，手机上长按卡片后拖动；队伍页同样可以拖动，编号会按顺序自动重排）；点进某个环节，页面最上方就是编辑表单（类型、说明、地址、线索原文、判定标准），改完点「保存修改」，附件和队伍完成情况在同一页下方。每个赛段固定以中继站结尾，结算时自动取它的签到时间。赛段一旦开始，环节的增删、顺序、类型、淘汰和熔断设置就锁定了，只有管理员能改；主办还能改说明、地址、时间这类文字内容。
- 环节类型决定默认行为，主办可逐个改：

| 类型 | 站点 | 手动记的时间 |
|---|---|---|
| SL 起跑线 | 需要 | 出发（没有开始时间） |
| RI 路线信息 | 不需要 | 到达 |
| TI 任务点 / DT 绕道 / RB 路障 / FF 快进 / Union 联合 / Shuffle 洗牌 / SB 减速带 / FO 对抗 / Trap 陷阱 | 需要 | 完成 |
| BR 支线 | 需要 | 开始支线 + 结束支线（主线暂停计时） |
| UT 回转点 / YD 让路点 | 需要 | 完成 + 施加对象 |
| PS 中继站 / 终点 | 需要 | 签到 |

  是否需要站点由类型决定，不能单独改；所有环节的开始时间都自动取上一个环节的结束时间。
- 每个环节可以配置多种「熔断」：名称、起始时间、间隔时间，货币模式还有每次消耗。队伍进入环节后到了起始时间第一次可用，每用一次就重新倒计时。
- 「排班」为每个赛段指定跟队（对应队伍）和站点（可以勾选多个环节）。同一队伍分了两个跟队或存活队伍没有跟队时页面会提示。

**赛中**
- 每个赛段出发前在「赛段」点「开始赛段」：状态变为进行中，本赛段经费自动发给所有存活队伍。赛段结束点「结束赛段」。
- 左侧（手机上向右翻一屏）随时看队伍当前位置；「进度」页看每队每个环节的开始、结束、用时。
- 任何记录都可以在环节详情页「修改记录」；罚时在「进度」页中间；经费变动或罚时记错了，只有发出这条记录的本人和主办能在对应列表里「撤销」，原记录划线保留，同时写一条反向记录，不会删除任何记录。
- 需要时在「公告」页发公告，重要的可以「置顶」；所有幕后的「公告」标签会出现红点，点开即消；已读状态记在账号上，换手机登录也不会重复提醒。

**赛段结束**
- 「进度」页的进度结算表会随签到和罚时自动更新名次并重新排序；淘汰按中继站的设置自动判定，核对名次即可。
- 「后台 → 备份与重置」导出一次备份。

**忘记密码**：主办在「账号管理」里重置。所有修改都在「操作日志」里可查，操作日志和备份/重置只有管理员账号能进。
